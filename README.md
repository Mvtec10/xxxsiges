# xxxsiges
Sistema de Gestão de Seguros

Este é um sistema de gestão de seguros desenvolvido com [Next.js](https://nextjs.org). Ele permite o gerenciamento de seguros de saúde, automóvel e residencial.

## 🚀 Como Iniciar o Projeto

Para rodar o servidor de desenvolvimento, use:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
